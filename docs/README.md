How the documents relate:

* [asr.md](asr.md) lists the architecturally significant requirements – what
  the design has to achieve and how each one is verified.
* [adr/](adr/README.md) records each significant decision taken to meet
  them, with the alternatives that were rejected.
* [architecture.md](architecture.md) describes the resulting structure.
* [design.md](design.md) goes one level deeper into each component.
